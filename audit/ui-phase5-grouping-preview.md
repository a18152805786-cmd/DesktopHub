## Safety decision

The preview is valid, but applying it to the real profile is deliberately blocked. DesktopFramesPlus renders Frame items as independent WPF icons and can only hide/show the complete native Desktop icon list. It has no per-icon visual ownership or positioning API. Applying these references while native icons remain visible would create visual duplicates; hiding all native icons would be the prohibited workaround.
